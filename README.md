# Adam's Portfolio

My personal portfolio website. It introduces me, tells visitors a little about me, and links to my other work on GitHub.

## What the project is

This is a simple one-page personal website built with **HTML** and **Tailwind CSS** (loaded from a CDN). The page includes:

- an introduction section with my name, age, and what I do
- an "About me" section describing my interest in web development
- pictures
- a "My links" section with a link to my GitHub profile/ repository

[https://adammo78912-ctrl.github.io/my-portfolio-/](https://adammo78912-ctrl.github.io/my-portfolio-/)

## How to run it locally

You do not need to install anything or run a build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/adammo78912-ctrl/my-portfolio-.git
   ```

2. Open the folder:

   ```bash
   cd my-portfolio-
   ```

3. Open `index.html` in your web browser (double-click the file, or use your browser's "Open file" option).

That's it — the site will load using the Tailwind CSS CDN.
