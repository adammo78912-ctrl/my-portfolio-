## How to run it locally

## How I made it

- Created a GitHub repository named my-portfolio-.
- Added index.html and wrote the page content in HTML: the introduction, "About me" section, and links.

- Adjusted the styling and text sizes until the page looked right.
- Enabled GitHub Pages (source: main branch, / root folder) so the site is available online.
- Removed an incorrect custom-domain CNAME file so the GitHub Pages demo link works.
